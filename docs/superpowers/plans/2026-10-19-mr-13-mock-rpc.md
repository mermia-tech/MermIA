# MR-13 Mock RPC server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/mock-rpc` answers the 11 read RPCs with figures computed from `fixtures/el_guero/`, validated with the C3 models, so Dev B can build the agent without Dev A's real database.

**Architecture:** A small FastAPI app. `POST /rpc/{name}` validates the body with the RPC's C3 args model and returns ONE fixed answer per RPC (its "canonical query", listed in the README), built from the fixture JSON and checked with `RpcEnvelope[RPCS[name].data]` before it is sent. `?variant=` picks an error or a special case. No response is stored on disk.

**Tech Stack:** Python 3.12, FastAPI, `mermia-contracts` (workspace), pytest + `TestClient`, uv.

**Spec:** `docs/kickoff/08-mvp-4-week-plan.md` (C3, C7, "Avoiding blocking"); `docs/superpowers/specs/2026-10-18-mr-11-contracts-rpc-tools-design.md` §7.1 and §7.2.

## Global Constraints

- `packages/contracts` is NOT touched. The C3 examples are not edited and not served (they disagree with the fixtures, see the README).
- Money is integer centavos with a formatted `text` (`"$184,320.50"`). Percentages are percent points (`"+7.2%"`). Margin and food cost are on the NET price (MR-11 D20).
- Nothing in the mock is invented without being marked: the `nulls` variant is synthetic and says so in the README and in a test name.
- "Today" is Monday 2026-10-12 (`expected.json`). Data ends on 2026-10-11.
- Code in English; the mock returns the text the contract already defines (es-MX figures).

## Review Focus

- An unknown `variant`, or one that does not exist for that RPC, is a 422, never a silent fallback to the normal answer.
- A body that fails the args model is a 422 (a bad `period`, an unknown field).
- An unknown RPC name is a 404.
- Every variant of every RPC validates against C3 (`ok=false` carries an error and no data).
- The pinned figures match the fixtures: Centro week $184,320.50 / $171,905.00, pastor margin 67.16 % on net, food cost 37.5 %, 17 cancelled tickets.
